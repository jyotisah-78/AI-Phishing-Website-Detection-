# AI Phishing Website Detection

A machine-learning project that classifies URLs as phishing or legitimate using URL text.

## Run locally

```bash
pip install -r requirements.txt
python src/app.py
```

## Run tests

```bash
python src/test_project.py
```

The prediction is an estimate based on URL text only. The app does not open or scan websites, so it cannot guarantee a website is safe.
